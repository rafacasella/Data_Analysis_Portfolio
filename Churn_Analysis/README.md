# 📉 Análise de Churn Bancário

## 📝 Descrição
Este projeto contém uma análise aprofundada de evasão de clientes (*churn*) utilizando dados bancários. O objetivo principal é identificar padrões de comportamento, características demográficas e fatores financeiros que levam os clientes a cancelarem seus serviços ou contas na instituição.

## 🛠️ Tecnologias e Ferramentas
* **SQL** (Construção de queries, agrupamentos, filtros e extração de métricas de negócio)
* **Banco de Dados Relacional** (PostgreSQL / MySQL / SQL Server)

## 📁 Estrutura de Arquivos
* `churn.sql`: Script contendo todas as consultas SQL estruturadas para a análise dos dados bancários.

## 📊 Principais Insights Buscados no Script
* Taxa geral de Churn da instituição.
* Análise de evasão por faixa etária e gênero.
* Impacto do saldo em conta e número de produtos contratados na fidelização do cliente.
* Relação entre clientes ativos/inativos e a taxa de cancelamento.
